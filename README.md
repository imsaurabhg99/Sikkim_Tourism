# incredible.sikkim

Tourism and trekking website for Sikkim, with an honest trip-cost estimator
(days × stay type × activities × season) in INR / USD / EUR.

## Status

**Design prototype.** `prototype/index.html` is a self-contained clickable
prototype (no build step) — open it in a browser, or serve it:

```bash
python3 -m http.server 4173 -d prototype
```

All rates are sample figures. Hero and card photographs are by Wikimedia
Commons contributors (CC BY / CC BY-SA / public domain).

The production build (Next.js: accounts, saved estimates, bookings) comes next.
